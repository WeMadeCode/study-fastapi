01本课目标

02背景回顾：项目里已有哪一半

位置现有行为扩展时的边界
app/main.py · lifespanstart → register_mcp_tools → yield → stop连接由应用生命周期管理,不在每个工具调用里重建。
app/services/mcp/client.pyinitialize、initialized、tools/list、tools/call目前没有资源与提示词方法,没有检查返回版本或按能力跳过发现。
scripts/l7_mcp_server.py只声明 tools,调用 execute_tool 检索知识库真实检索依赖配置/embedding/数据库;协议实验先用固定数据。
tools.py · get_all_tool_schemasMCP 元数据转换成模型工具 schema,同名覆盖内置并非所有 MCP inputSchema 都能诚实 cast 到项目的扁平 _ParamsSchema。

现有 McpClient._recv 每次调用自己 readline,且用共享 self._request_id 等待结果。不同会话共享同一个 client,可能并发进入,即使单个 agent 内部顺序调用也会争抢响应。它还会跳过不匹配的消息,若其中是另一个调用的响应,这个响应便丢了。stop 当前 terminate 后未 wait,也值得在正式化时补齐。

03原理：三类原语与上下文入口

原语通常由谁决定使用数据形状如何进入模型
tools模型选择,host 执行inputSchema 定义参数;结果 content/isErrorhost 将结果写入绑定 tool_call_id 的 tool 消息。
resourceshost 选择,也可提供 UI 供用户选URI + contents;文本 text 或二进制 blobhost 读取后将其作为有来源的参考资料注入。
prompts用户选择模板,host 展开字符串参数 → user/assistant messageshost 按内容类型映射为模型消息,不会自动启动推理。
initialize(协商版本/能力) → notifications/initialized(不回复)
→ 发现目录 → 选择 URI / 名称 → read / get / call
→ 验证 JSON-RPC 外壳 → 验证业务 result → host 决定使用方式

列目录不是读全文。资源模板 resources/templates/list 描述 URI 模式,不是穷举所有资源；资源和提示词可以按需加载,不必一启动就塞进模型。目录可能返回 nextCursor,正式 client 应循环翻页并合并结果。示例固定一页,若出现游标就让断言失败,不能悄悄丢后续页。

失败表现接收方动作
JSON 语法错误-32700定位发送端序列化或 stdout 污染。
未知方法/非法参数-32601 / -32602修正请求,保留服务端错误信息。
资源不存在-32002换合法 URI,不把空内容当成功。
工具业务失败result.isError=true协议仍成功,将业务错误作为结果交回模型。
EOF/超时/取消本地连接异常清理连接;不能靠重复调用掩盖失败。

核对依据：生命周期 · Tools · Resources · Prompts

04动手一：提供三类能力的离线 server

创建 scripts/t3_mcp_server.py。这里 search_knowledge_base 使用固定文本,保留业务工具名称以便对照 L7,但它不是实际 RAG。stdout 只输出一行一个 JSON；将诊断写入 stderr。服务端只支持文本、小消息和串行处理,不声明可选订阅能力。

类型推导：为什么不直接 return 字典？

多种嵌套字典与空字典可能让编辑器把 dispatch 的返回类型推导为含 Unknown 的联合类型。函数开头只声明一次 result: dict[str, object]，每个分支先赋值再 return result，为字典字面量提供类型上下文，也保留本项目省略返回类型的约定。

object 表示值可以是任意对象，但使用其具体操作前仍需收窄；它不是绕过检查的 Any。这层只组装并序列化结果，不保证递归 JSON 合法性，也不验证每种 MCP result 的完整形状；读取具体字段时仍应使用 Pydantic 或 TypedDict 合同。不要用 cast 或 type: ignore 掩盖推导问题。

由你创建：scripts/t3_mcp_server.py

"""T3 离线协议实验台:只提供固定文本,不访问真实知识库。"""

import json
import sys

from pydantic import BaseModel, ConfigDict, Field, ValidationError

VERSION = "2025-06-18"
URI = "study://kb/usage-guide"
TEXT = "检索片段只是证据,需要核对相关性。"


class Request(BaseModel):
    model_config = ConfigDict(strict=True)
    jsonrpc: str
    id: int | str | None = None
    method: str
    params: dict[str, object] = Field(default_factory=dict)


class ToolArgs(BaseModel):
    model_config = ConfigDict(strict=True, extra="forbid")
    question: str


class PromptArgs(BaseModel):
    model_config = ConfigDict(strict=True, extra="forbid")
    question: str
    result: str


def send(message: dict[str, object]):
    print(json.dumps(message, ensure_ascii=False), flush=True)


def dispatch(req: Request):
    result: dict[str, object]  # 异构字典需要类型提示,返回类型由此推导。
    if req.method == "initialize":
        result = {
            "protocolVersion": VERSION,
            "serverInfo": {"name": "t3-lab", "version": "0.1"},
            "capabilities": {"tools": {}, "resources": {}, "prompts": {}},
        }
        return result
    if req.method == "tools/list":
        result = {
            "tools": [
                {
                    "name": "search_knowledge_base",
                    "description": "离线固定检索样本",
                    "inputSchema": ToolArgs.model_json_schema(),
                }
            ]
        }
        return result
    if req.method == "tools/call":
        if req.params.get("name") != "search_knowledge_base":
            raise ValueError("未知工具")
        args = ToolArgs.model_validate(req.params.get("arguments", {}))
        failed = args.question == "模拟失败"
        text = json.dumps({"error": "模拟检索失败"} if failed else {"result": [{"content": TEXT}]}, ensure_ascii=False)
        result = {"content": [{"type": "text", "text": text}], "isError": failed}
        return result
    if req.method == "resources/list":
        result = {"resources": [{"uri": URI, "name": "kb-guide", "mimeType": "text/plain"}]}
        return result
    if req.method == "resources/read":
        if req.params.get("uri") != URI:
            raise FileNotFoundError("资源不存在")
        result = {"contents": [{"uri": URI, "mimeType": "text/plain", "text": TEXT}]}
        return result
    if req.method == "prompts/list":
        result = {
            "prompts": [
                {
                    "name": "review_retrieval",
                    "description": "分析检索证据",
                    "arguments": [{"name": "question", "required": True}, {"name": "result", "required": True}],
                }
            ]
        }
        return result
    if req.method == "prompts/get":
        if req.params.get("name") != "review_retrieval":
            raise ValueError("未知提示词")
        prompt_args = PromptArgs.model_validate(req.params.get("arguments", {}))
        result = {
            "messages": [
                {
                    "role": "user",
                    "content": {
                        "type": "text",
                        "text": f"问题:{prompt_args.question}\n证据:{prompt_args.result}\n请解释证据是否足够。",
                    },
                }
            ]
        }
        return result
    raise NotImplementedError("未知方法")


def main():
    initialized = False
    ready = False
    for line in sys.stdin:
        try:
            raw = json.loads(line)
            req = Request.model_validate(raw)
            if req.jsonrpc != "2.0":
                raise ValueError("jsonrpc 必须为 2.0")
        except json.JSONDecodeError:
            send({"jsonrpc": "2.0", "id": None, "error": {"code": -32700, "message": "JSON 解析失败"}})
            continue
        except (ValidationError, ValueError):
            send({"jsonrpc": "2.0", "id": None, "error": {"code": -32600, "message": "非法请求"}})
            continue
        if req.id is None:
            if initialized and req.method == "notifications/initialized":
                ready = True
            continue  # 通知不回复;本实验不支持客户端发来的其他通知。
        try:
            if req.method != "initialize" and not ready:
                raise ValueError("尚未完成初始化")
            result = dispatch(req)
            if req.method == "initialize":
                initialized = True
            send({"jsonrpc": "2.0", "id": req.id, "result": result})
        except (ValueError, FileNotFoundError, NotImplementedError) as exc:
            code = (
                -32002
                if isinstance(exc, FileNotFoundError)
                else -32601
                if isinstance(exc, NotImplementedError)
                else -32602
            )
            send({"jsonrpc": "2.0", "id": req.id, "error": {"code": code, "message": str(exc)}})


if __name__ == "__main__":
    main()
代码位置关键解释
Request.model_validate解析后立即验证 envelope,params 收窄为 dict[str, object]。
ToolArgs / PromptArgs外部 arguments 再单独验证,禁止把字典键存在误当作类型正确。
dispatch每个 method 返回 result 的内容,统一由 main 加 jsonrpc 和 id。
initialized / ready已返回 initialize 和已收到 initialized 是两个状态。
isError固定问题“模拟失败”用于检查业务错误合同,没有进行真实检索。

这是教学协议子集：未实现批处理、server→client 请求、取消通知、多媒体、动态清单和订阅。2025-06-18 的订阅可使用 resources/subscribe 与通知,后续版本需要另按规范核对；本课不混用版本。

05动手二：完整请求加锁的 client

创建 scripts/t3_mcp_client.py,与 server 放同一目录。客户端启动后检查版本与能力,然后发无 id 的 initialized 通知。request 把 id 分配、写入和读取包在同一把锁内；超时或取消会关闭连接。

由你创建：scripts/t3_mcp_client.py

"""T3 用户抄入 scripts/t3_mcp_client.py,与同目录的 t3_mcp_server.py 配套。"""

import asyncio
import json
import sys
from asyncio.subprocess import Process
from contextlib import suppress
from pathlib import Path
from typing import Literal

from pydantic import BaseModel, ConfigDict, Field


class RpcError(BaseModel):
    code: int
    message: str


class Envelope(BaseModel):
    model_config = ConfigDict(strict=True)
    jsonrpc: Literal["2.0"]
    id: int | str | None = None
    method: str | None = None
    result: dict[str, object] | None = None
    error: RpcError | None = None


class InitResult(BaseModel):
    protocolVersion: str
    capabilities: dict[str, dict[str, object]]


class TextBlock(BaseModel):
    type: Literal["text"]  # 本练习只支持文本,遇到其他类型明确验证失败。
    text: str


class CallResult(BaseModel):
    content: list[TextBlock]
    isError: bool = False


class ResourceContent(BaseModel):
    uri: str
    text: str


class ReadResult(BaseModel):
    contents: list[ResourceContent]


class PromptMessage(BaseModel):
    role: Literal["user", "assistant"]
    content: TextBlock


class PromptResult(BaseModel):
    messages: list[PromptMessage]


class ToolMeta(BaseModel):
    name: str
    inputSchema: dict[str, object]


class ToolList(BaseModel):
    tools: list[ToolMeta]
    nextCursor: str | None = None


class ResourceMeta(BaseModel):
    uri: str
    name: str


class ResourceList(BaseModel):
    resources: list[ResourceMeta]
    nextCursor: str | None = None


class PromptMeta(BaseModel):
    name: str
    # 工厂本身也明确元素类型,避免 list[Unknown]。
    arguments: list[dict[str, object]] = Field(default_factory=list[dict[str, object]])


class PromptList(BaseModel):
    prompts: list[PromptMeta]
    nextCursor: str | None = None


class RemoteError(RuntimeError):
    def __init__(self, error: RpcError):
        super().__init__(f"{error.code}: {error.message}")
        self.code = error.code


class LabClient:
    def __init__(self):
        self.proc: Process | None = None
        self.next_id = 0
        self.lock = asyncio.Lock()
        self.capabilities: dict[str, dict[str, object]] = {}

    async def start(self, server: Path):
        self.proc = await asyncio.create_subprocess_exec(
            sys.executable,
            str(server),
            stdin=asyncio.subprocess.PIPE,
            stdout=asyncio.subprocess.PIPE,
            stderr=None,
        )
        try:
            raw = await self.request(
                "initialize",
                {
                    "protocolVersion": "2025-06-18",
                    "capabilities": {},
                    "clientInfo": {"name": "t3-host", "version": "0.1"},
                },
            )
            init = InitResult.model_validate(raw)
            if init.protocolVersion != "2025-06-18":
                raise RuntimeError("本实验只实现 2025-06-18,拒绝未知版本")
            self.capabilities = init.capabilities
            await self.send({"jsonrpc": "2.0", "method": "notifications/initialized"})
        except BaseException:
            await self.close()
            raise

    async def send(self, payload: dict[str, object]):
        if self.proc is None or self.proc.stdin is None:
            raise RuntimeError("未连接")
        self.proc.stdin.write((json.dumps(payload, ensure_ascii=False) + "\n").encode())
        await self.proc.stdin.drain()

    async def request(self, method: str, params: dict[str, object]):
        capability = method.split("/", 1)[0]
        if capability in {"tools", "resources", "prompts"} and capability not in self.capabilities:
            raise RuntimeError(f"server 未声明 {capability}")
        # 必须覆盖“取 id → 写 → 读”全程,只锁写入无法防止两个 readline 争抢。
        async with self.lock:
            if self.proc is None or self.proc.stdout is None:
                raise RuntimeError("未连接")
            self.next_id += 1
            request_id = self.next_id
            try:
                async with asyncio.timeout(2):
                    await self.send({"jsonrpc": "2.0", "id": request_id, "method": method, "params": params})
                    while True:
                        line = await self.proc.stdout.readline()
                        if not line:
                            raise RuntimeError("server 提前关闭 stdout")
                        response = Envelope.model_validate_json(line)
                        if "id" not in response.model_fields_set:
                            if not response.method:
                                raise RuntimeError("非法通知")
                            # 最小版只观察通知;不能在这里悄悄实现 server→client 请求。
                            print("通知:", response.method)
                            continue
                        if response.id != request_id:
                            raise RuntimeError("响应 id 不匹配,串行连接已失去同步")
                        if (response.result is None) == (response.error is None):
                            raise RuntimeError("result/error 必须恰好有一个")
                        break
            except BaseException:
                # 超时/取消后关闭连接,不能把迟到响应误分给下一次请求。
                await self.close()
                raise
            if response.error is not None:
                raise RemoteError(response.error)
            assert response.result is not None
            return response.result

    async def close(self):
        proc = self.proc
        self.proc = None
        self.capabilities = {}
        if proc is None:
            return
        if proc.stdin is not None:
            proc.stdin.close()  # stdio 生命周期:EOF 先给 server 正常退出机会。
        try:
            await asyncio.wait_for(proc.wait(), 0.5)
        except TimeoutError:
            if proc.returncode is None:
                with suppress(ProcessLookupError):
                    proc.kill()
            await proc.wait()


async def main():
    client = LabClient()
    try:
        await client.start(Path(__file__).with_name("t3_mcp_server.py"))
        tools = ToolList.model_validate(await client.request("tools/list", {}))
        resources = ResourceList.model_validate(await client.request("resources/list", {}))
        prompts = PromptList.model_validate(await client.request("prompts/list", {}))
        assert tools.nextCursor is resources.nextCursor is prompts.nextCursor is None
        assert tools.tools[0].name == "search_knowledge_base"
        uri = resources.resources[0].uri
        read = ReadResult.model_validate(await client.request("resources/read", {"uri": uri}))
        prompt = PromptResult.model_validate(
            await client.request(
                "prompts/get",
                {
                    "name": prompts.prompts[0].name,
                    "arguments": {"question": "怎样判断证据?", "result": read.contents[0].text},
                },
            )
        )
        assert prompt.messages[0].role == "user"
        succeeded = CallResult.model_validate(
            await client.request(
                "tools/call",
                {"name": "search_knowledge_base", "arguments": {"question": "怎样判断证据?"}},
            )
        )
        assert not succeeded.isError and succeeded.content[0].text
        failed = CallResult.model_validate(
            await client.request(
                "tools/call",
                {
                    "name": "search_knowledge_base",
                    "arguments": {"question": "模拟失败"},
                },
            )
        )
        assert failed.isError
        error_cases: list[tuple[str, dict[str, object], int]] = [
            ("resources/read", {"uri": "study://missing"}, -32002),
            ("prompts/get", {"name": "review_retrieval", "arguments": {}}, -32602),
        ]
        for method, params, expected in error_cases:
            try:
                await client.request(method, params)
            except RemoteError as exc:
                assert exc.code == expected
            else:
                raise AssertionError("应该返回协议错误")
        # gather 并发进入,锁保证底层按一次完整 RPC 串行完成。
        results = await asyncio.gather(*[client.request("resources/read", {"uri": uri}) for _ in range(3)])
        assert len(results) == 3
        print("T3:三原语、业务错误、协议错误、并发进入串行完成均通过")
        print("准备交给模型的 prompt:", prompt.messages[0].content.text)
    finally:
        await client.close()


if __name__ == "__main__":
    asyncio.run(main())

这里用 Pydantic 的 Literal 限定文本内容,所以收到图片时会明确失败,不会像当前 ContentBlock 的空字符串默认值那样把未知内容静默丢掉。把“只支持文本”暴露成可检查的边界,比假装兼容全部 MCP 内容更利于调试。

close 先关闭 stdin 给出 EOF,等待一小段退出宽限,仍不退出才 kill 并 wait。这个 0.5 秒是关闭期限,不是用定时器猜测执行顺序。连接超时后不复用它,避免迟到响应混进下一次调用。

06接回现有 Agent：发现、映射、执行

tools/list → McpToolMeta → register_mcp_tools
→ get_all_tool_schemas → 模型提出 tool_call
→ execute_tool → call_tool → tool result → 下一轮模型

正式代码接入时,把 request 和 close 的协议逻辑移到现有 McpClient,让 start、call_tool、read_resource、get_prompt 都经过同一个 request。不要给每个方法再写一个读取 stdout 的循环。对于 resources/prompts,需要 host 明确入口,不能一律塞进 TOOL_REGISTRY 伪装成模型工具。

# 放在 agent.py 等允许 SDK 类型的组装边界；以下为文本 prompt 的完整转换函数。
# PromptResult 为本课 client 定义的模型，正式化后从 services/mcp 导入。
def prompt_to_messages(prompt: PromptResult):
    converted: list[ChatCompletionMessageParam] = []
    for item in prompt.messages:
        if item.role == "user":
            converted.append({"role": "user", "content": item.content.text})
        else:
            converted.append({"role": "assistant", "content": item.content.text})
    return converted

上面使用 agent.py 已有的 ChatCompletionMessageParam。用户选模板后,host 才 get_prompt 并调用转换；返回的 messages 由应用明确决定是否持久化。资源正文应标注 URI 并作为参考数据,不要因为来自 MCP 就升格为全局 system 规则。完整多媒体映射和 UI/路由入参属于后续产品接入,这份协议实验不伪造已经实现。

若需要真正并发 RPC,改成一个后台 reader 持续读取,用 pending[id] → Future 分发。写请求先登记 Future 再发送；响应到来完成对应 Future；通知进入专门队列；EOF 使所有 pending 失败。server→client 请求带 id 和 method,不能当作通知跳过。超时还要处理晚到响应和 pending 清理。先掌握串行锁,再引入这套额外状态。

07思考题与详解

为什么 asyncio.gather 在本课能成功,却不代表 server 并行执行？

锁把底层 RPC 串行化。gather 只使多个调用同时等待入口,保护正确性后吞吐仍受顺序处理限制。

为什么资源与只读工具都能提供数据,还要区分？

关键在交互合同：工具面向一次操作与参数,资源面向 URI 标识的数据。只读并不能自动决定它必须是 resource,要看 host 怎样发现和使用。

提示词模板返回 messages 后,模型已经回答了吗？

没有。模板可以在 server 上生成消息,但模型调用由 host 决定。若 server 自己做推理,那是另一个显式设计,不能从 prompts/get 推断。

MCP schema 能直接 cast 成项目 ToolParam 吗？

只能在形状确实兼容时。项目 _ParamsSchema 只支持较窄的属性形状,外部 schema 可能有数组、嵌套对象、枚举等。cast 不转换也不验证,第三方接入要调整合同和验证策略。

08验证实验

uv run python -m ruff check scripts/t3_mcp_server.py scripts/t3_mcp_client.py
uv run python -m mypy --check-untyped-defs scripts/t3_mcp_server.py scripts/t3_mcp_client.py
uv run python scripts/t3_mcp_client.py

断言覆盖三类目录、资源读、模板展开、工具业务失败、错误 URI、缺参数、多个调用同时进入 client。再做三个故障实验：① server 往 stdout 打一行普通日志,应触发解析失败并清理连接；② initialize 返回不支持的版本,client 应拒绝；③让一个 method 延迟超过 2 秒,应超时并关闭。每次实验后恢复代码。

协议实验无需 .env、数据库和模型。真实 L7 server 的 tools/call 仍需 embedding 与数据库,不能将离线固定返回的通过视为实际知识库验证通过。
